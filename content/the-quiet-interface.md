# The quiet interface

There is a moment, somewhere around the third revision, when a piece of writing stops being an argument and starts being a shape. You feel it before you can name it — the paragraphs settle into a rhythm, the sentences stop fighting each other, and the thing you meant to say is finally sitting there on the page, patient and unremarkable.

Most software fights this moment. It offers you a toolbar of forty-seven ways to interrupt yourself, and every one of them is a small invitation to stop thinking about the sentence and start thinking about the formatting.

> A calm surface is not a lack of power. It is power that has been made quiet enough to work with.

_Italics_ are the smallest possible emphasis: a voice leaning forward for half a second. Headers are doors. Blockquotes are the argument stepping aside to let someone else speak, and they should be rare enough that when one appears, it means something.

The rest is mostly restraint. No tables in a draft. No code blocks in an essay. If a paragraph needs a diagram, the paragraph is not finished yet — see [the draft notes](https://example.com/notes) for the longer version of that complaint.

What the tools should do, then, is hold the document steady while the thinking moves. Sync in the background. Save without ceremony. Let the phone pick up the sentence the desktop started, mid-word if necessary, and never ask which version is current — because there is only one version, and it is the one you are both looking at.

That is the whole promise, really. Not more features. Fewer interruptions between the person and the paragraph.
